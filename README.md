Online Order Count Analysis 📊

Project Overview: 
Online Order Count Analysis is a data analytics project developed using Python. It focuses on analysing online shopping orders to understand sales patterns and product performance.

Technologies Used: 
Python,
Pandas,
Matplotlib,
CSV Dataset

Key Features: 
Analyse online order data,
Calculate total sales and revenue,
Identify top-selling products,
Analyse product categories,
Visualise sales data using charts

Dataset: 
The project uses an online orders dataset containing information such as order ID, product name, category, price, quantity, order date, city and total amount.

Project Objective: 
To understand online shopping trends and extract useful insights from order data using Python.

Project Type: BCA Internship Project

Domain: Data Analytics
